# Testing 1

A two-player village game. The host plays the boy. The player who joins plays the girl.

Play in the browser: https://thomakhy025-code.github.io/testing-1/

Opening that page starts the village. Each visitor gets their own session, because a browser cannot accept a second player's connection. Walk with the on-screen stick or the keys. A small tilt walks, a full tilt runs.

The Windows build is the two-player game. One person presses Host. The other launches the build, enters the host address, and presses Join. On the same computer the address is `127.0.0.1`.

Sword hits take 20 blood. Landing a forward flip cracks the ground.
